连接节点

填 host:port（P2P 种子：本节点主动去认识它，连上后按直邻交换供给）或 http(s):// 地址（自愿公共节点：搜索时向它查目录）。两种输入语义不同，不会合并成一个「已连接」。

主动连接只解决「我认识谁」：对方在 NAT 后面且没有可达入口时仍然连不上，需要它自己拨出或改用密封中继。连上也只能看到对方的直邻供给，那是"够用"，不是全网目录。
