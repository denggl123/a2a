### VPN 判断修正

不能把发现 XxYun 虚拟网卡视为故障原因，关闭 VPN 也不是继续安装的前提。VPN 可能是访问服务器所需的出口，应保持开启并对比不同线路、代理规则和服务器限制。

本轮通过同一个 `127.0.0.1:7892` SOCKS 入口实测：服务器 80 返回 HTTP 响应，443 完成 TLS 握手；服务器 22 立即关闭连接。对照 `ssh.github.com:443` 能收到 SSH 握手，而 `github.com:22` 同样立即关闭。该现象提示当前出口到 22 端口的限制，仍不能单凭这些结果确定限制位于 VPN、网络线路还是目标端。绑定 WLAN 源地址可收到服务器 SSH 握手，调整单连接参数后一度进入认证阶段，但重试仍超时，尚未形成稳定管理通道。没有关闭 VPN 或更改其全局配置。
