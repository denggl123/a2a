# 0.2.0b2 收尾交付与验收（2026-10-11）

## 本轮完成

1. **普通 SDK 调用接入自动结算。** 供应方限定支持方式；使用方设置顺序、金额与手续费上限，并明确开启自动授权。冻结首次报价、任务和支付计划；关闭授权后不会新付款，已有原单继续核对。积分、原生币与 x402 复用支付协调层，发现、筛选和评分不执行支付。
2. **常驻后台恢复。** 重启后恢复原单，有限队列、逐笔轮转、退避和诊断；控制台只读轮询。原生币丢响应恢复原交易；积分多方提交和 x402 原授权分别使用原有模块的恢复流程。不会切换支付方式、重复扣款或重复执行未知 Agent。
3. **交付丢响应恢复。** 签名节点报价绑定的原任务标识允许查询原回执，免费样品及已付款调用均已验证。查询未授权、找不到任务、返回错误任务或无效状态保留交付未知；只有有效原任务明确返回失败才计为失败。旧版本误记的查询错误会重新进入原单恢复，信用事实恢复 UNKNOWN。
4. **私人八维偏好学习。** 通过小型事实端口读取本人明确授权的已交付评价。质量、信用、速度、网络、成本等权重可拟合；按时间留出验证，限制供应方影响和每项变化，通过验证后本人明确采用。撤回、版本冲突、预算和支付规则均独立。控制台已接入。当前真人记录为 0，保持原偏好，工程调用不能冒充真人校准。
5. **发布规范与全套安装。** 五个包、源码包和 Windows 全功能单文件统一为 0.2.0b2；许可证、依赖许可证、统一文档、标准接入说明、自动验收工作流、发布清单、项目签名与真实运行自检均已补齐。旧平台不再作为第二套交易体系。
6. **本机测试支付环境修复。** 修复测试链状态卷权限、历史回执持久化和启动校验；旧卷原样保留。新测试链代币与四节点配置成对迁移。测试专用 nonce 修复只重投原始相同交易，不重签付款、不改业务账本；常规重启无需迁移修复。
