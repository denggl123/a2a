# 私人八维偏好学习

默认推荐仍是均衡设置，质量与诚信优先。学习模块提供本人偏好建议，默认不自动采用，不改变发现、公开信用、争议处理或支付规则。

## 数据与模块边界

`SelectionFactAdapter.preference_observations` 读取本机明确选用的候选快照、已核验交付事实及任务评价，投影成八个 0–1 特征和一个本人效用标签。学习算法只依赖该小端口和本机存储，不直接认识评价账本、网络或支付模块。未知、过期和冲突特征采用排序时相同的中性值 0.5。

原始输入、输出、凭据与钱包地址不进入学习数据。选用记录、候选快照、任务评价、学习建议和采用记录分别保存在既有加密本机数据库。建议只存权重、支持量、验证误差和数据摘要；不会对外发布。

只有本人明确授权、PRODUCTION、HUMAN、非自用且已核验交付的事先选用记录可训练。CONTROLLED 工程记录、ASSISTANT 代评、撤回或未授权评价全部排除；同一交易只保留最新评价，不能通过撤回最新记录重新启用旧评价。本人效用 1–5 分映射为 0–1，不把结果称为客观正确率或独立用户认证。

## 学习与采用规则

1. 读取当前偏好版本的选用快照，最多检查最近 5,000 次选用；训练只使用最近 90 天最多 1,000 笔交易，每个供应方最多 100 笔。
2. 至少 40 条真人评价、3 个供应方、3 个日期，并且效用具有差异；不足时保持原权重。
3. 按评价时间划分前 80% 训练、后 20% 验证，验证至少 8 条。两部分均须含至少两个供应方；按供应方平衡影响。
4. 使用带原权重约束的梯度拟合，八项合计为 1、每项变化最多 5 个百分点。质量和信用的下限尊重本人已明确设置的较低值。
5. 验证误差须相对下降至少 5%，同时绝对下降至少 0.0001，才产生 READY 建议。没有改善时不生成可采用的新权重。
6. 本人点击采用时重新核对数据摘要、撤回情况与偏好版本。数据或本人设置变化则拒绝旧建议。只更新八项权重，原预算、硬性要求和支付授权完全独立。

控制台「发现 → 调整偏好与要求 → 从本人评价学习偏好」可生成建议；通过验证后才显示采用按钮。当前受控调用不满足真人历史要求，不能靠这些记录自动宣布偏好已经校准完成。

## 本机受保护接口

- `GET /v1/selection/learning`：模块状态及最近五个本机建议；不训练。
- `POST /v1/selection/learning/fit {profile_id}`：读取本人已授权历史，生成建议或明确的资料不足状态。
- `POST /v1/selection/learning/apply {candidate_id, expected_revision}`：复核原数据及版本，采用建议。

任务质量的效用校准仍由独立的 CalibrationService 负责。它将具体任务的客观检查映射到本人效用；本模块学习的是八项推荐维度的相对权重，两者不能互相代替。
