# 产品化收口：一键装 + 失败/争议处理

> 本文记录 2026-09-28 落地的「产品化收口」三块，以及**刻意不做**的部分。
> 口径以 [`PRODUCT.md`](PRODUCT.md)（时刻 1 / 时刻 3 / 时刻 4）与
> [`SOVEREIGN.md`](SOVEREIGN.md)（第四节边界）为准；冲突时以它们为准。

## 1. 一键装（时刻 1：双击，然后什么都不做）

```bash
python scripts/bootstrap.py            # 干跑看它要做什么：加 --dry-run
                                       # 只查环境对不对：加 --check
```

Windows 直接**双击** `scripts\bootstrap.cmd`。

- 真正的实现在 `scripts/bootstrap.py`（纯标准库、跨平台）；`.sh` / `.cmd` 只是
  "找到 Python 并转交"的薄壳。`.cmd` **必须纯 ASCII**（cmd.exe 按系统代码页解析，
  中文注释会被当命令执行 —— 踩过）。
- **幂等**：重复跑只是重新对一遍，不会把已有环境弄乱；没有 `.venv` 才建。
- **干跑与真跑共用同一份 `plan()`** —— 杜绝"干跑看到的 ≠ 真跑做的"两条路漂移。
- 装完**必定自检**一遍 `import a2n_node / a2n_sdk / a2n_p2p / a2n_acceptance / a2n_kernel`
  （`bootstrap.py` 的 `CHECK_IMPORTS`，即全部 5 个包）：装机脚本最贵的错是
  **假成功**（装完却起不来，用户以为坏了就卸载）。任何一步失败立刻非零退出并说明卡在哪。
- 为什么本地包用 `--no-deps`：`requirements.txt` 已装齐第三方依赖，而 `a2n-*` 尚未发布到 PyPI。
- 只留这一条路：装的时候**不该有问题要用户回答**（没有注册、没有偏好、没有"是否允许"）。

## 2. 失败 / 未知：如实呈现，不伪装成成功或收入

`docs/PRODUCT.md` 时刻 3：**没有签收的钱不许显示为收入，宁可显示"待对方确认"。**

- 调用记录的状态文案补全，且区分三态：
  - **已完成**：`已结算 / 已验收 / 已完成`；
  - **失败**：`失败 / 被拒绝 / 等待超时 / 对方不可达 …`（有明确结论）；
  - **结果未知**：`结果未知 · 已发出未确认 / 已中断 · 结果未知 / 取消中 · 结果待确认`
    —— 单独一类，**绝不与"已完成"混为一谈**。
- `unknownState(state)` 把"已发出但没收到确认"的三种状态显式圈出来；控制台可以据此
  把它标成"未确认"，而不是算进"成功"。未登记的状态**原样回显**，不猜。
- 落点：`packages/a2n-sdk/src/a2n_sdk/web/runtime.html`（`statusLabel` / `unknownState`），
  纯逻辑断言在 `scripts/runtime_logic_check.js`。

## 3. 争议：本机「这单我不认」（时刻 4）

`docs/PRODUCT.md` 时刻 4：**结果不好时，用户要有"这单我不认"的动作，而这个动作本身要
产生一份"我不认"的凭证。"没有仲裁员"不等于"用户没处说话"。**

实现：`a2n_sdk.disputes.DisputeBook`（跑在节点自己的 `LocalStore` 上）+
控制台「我不认的记录」面板 + 调用记录行内按钮。

**它是什么**：把"谁、对哪一笔、为什么不认、什么时候说的"固化成一条本机留存记录，
带一个内容**指纹 `digest`**，事后可拿它对"这份记录有没有被改过"。可**撤回** ——
撤回同样留痕（`state=WITHDRAWN` + `withdrawn_at`），**不抹记录**（抹掉 = 事后翻脸无据）。

**它不是什么（边界写死在数据里）**：`kind="local_rejection_not_arbitration"`。
自持模式**没有第三方裁决**（`SOVEREIGN.md` 第四节），所以：
- **不自动退钱** —— 钱在谁手里、要不要退，是双方自己的事；
- **不代对方裁定、不假装有裁决结果** —— 前端不许把它画成"平台判我赢了"；
- **只能对"本机真有的一笔"开单** —— 对查无此单的任务说不认，等于伪造无对象的指控。

历史上还有一条**平台模式的仲裁线**（`a2n_acceptance.dispute`，L4 仲裁工单，跑在
`a2n_store` 上、带裁定与退款执行）；它在 2026-10-05 收口时与旧平台一并退役
（见 [RETIRED-PLATFORM.md](RETIRED-PLATFORM.md)）。**现在只剩自持模式这一条，不共用一张表。**

## 刻意不做（避免把"没有的东西"说成有）

- 不做仲裁流程 / 客服工单 / 运营介入 —— 那是把"没有仲裁员"这条形状改掉。
- 不做"不认就冻结资金" —— 自持模式没有托管，冻结是空话。
- 不做自动开单 —— 主动出现的界面要回答"用户此刻不处理会有什么损失"（原则⑥），
  答不出来就不许出现；"不认"是用户的动作，不是系统的推送。
