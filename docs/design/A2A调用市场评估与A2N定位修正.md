# A2A 调用市场评估 & 对 A2N 定位的修正建议

> 评估日期：2026-09-08
> 评估对象："Agent 调用 Agent 并按次付费"这个市场值不值得做、A2N 该站在哪
> 结论一句话：**市场是真的，协议层已经不用你做了，真正的真空在"调用完之后谁验收、谁记账、谁担责"——但原方案的收入模型必须改。**

---

## 1. 先看事实：这个市场现在走到哪了

### 协议层：已经打完了，别再自造轮子

| 层 | 协议 | 状态 |
|---|---|---|
| 工具调用 | MCP（2024.11，已捐 Linux 基金会） | 事实标准 |
| Agent 互调 | **A2A v1.0 稳定版**（2026.3.12） | **已定局** |
| 支付授权 | AP2（Google，60+ 机构，2026.4 捐 FIDO 联盟） | 巨头主导 |
| 结算执行 | x402（Coinbase/Cloudflare）、MPP（Stripe/Tempo） | 链上已跑量 |
| 商务流程 | ACP（OpenAI+Stripe）、UCP（Google+Shopify+沃尔玛） | 零售场景 |
| 身份信誉 | ERC-8004（2026.1 主网，注册量 42 万+） | 链上派系 |
| 中国路线 | 银联 APOP、支付宝 ACT、京东 A2P2、微信 AI 专属卡 | 持牌主导 |

A2A 一年成绩单：150+ 生产组织、22K stars、五语言 SDK、v1.0 带**签名 Agent Card**（跨域密码学身份验证）、微软 Copilot Studio / Azure AI Foundry / AWS Bedrock AgentCore 全部原生支持。

**对你的意义：SDK 直接发 Agent Card、调度器直接读 Agent Card，一整套"能力发现"设计可以删掉。省两周，还天然跨生态。**

### 中国监管：2026.8.24 的公约是分水岭

中国支付清算协会《智能体支付应用自律公约》（中支协发〔2026〕128号）八章三十四条，三条直接改变格局：

1. **KYA（了解你的智能体）**——在 KYC 之上，对接入支付链路的智能体做身份识别、验证、**高中低风险分级**，且身份信息在支付全链路传递。
2. **自主支付三阶段报备**——辅助支付 / 预设条件下自主支付 / 泛条件自主支付，后两种上线前必须报备并通过业务有效性、技术安全性、伦理符合性评估。
3. **核心环节必须持牌**——账户管理、交易处理、资金清结算只能由持牌机构做，"谁提供支付服务谁负责"。

**这三条对 A2N 全是好消息。** 原设计里"资金只在持牌托管体系内流动、运营方零接触"的架构，恰好就是公约要求形态。你不是被监管拦住，你是提前两年站到了正确的一侧。

## 2. 但需求要拆开看：三类真，一类假

**真需求（会有人掏钱）：**
- **算力类**：GPU 时、推理、渲染、批处理。单价高（几元到几千元），已有成熟付费习惯。
- **专业能力类**：翻译、法律检索、医疗标注、设计、审计。单价中高，验收标准可定义。
- **数据与工具类**：搜索、OCR、验证码、合规查询。高频低价。

**假需求（别赌它）：**
- **同一组织内部的多 Agent 编排**。这类用 LangGraph / CrewAI 就够了，内部调度的交易成本为零，**根本不需要市场**。而今天生产环境里跑的 A2A 部署，绝大部分恰恰是这一类（保险理赔在 intake / 反欺诈 / 核赔 agent 之间流转）。

**关键判断：跨主体的付费调用今天极少，因为它缺三样东西——身份、结算、验收。前两样巨头正在补，第三样没人做。这就是 A2N 的窗口，也是这个市场还没起来的原因。**

---

## 3. 一个必须直面的数字：微支付撑不起 3%

x402 一年成绩：1.76 亿笔、结算额约 **7300 万美元**。
- 76% 的单笔金额低于 0.30 美元（Visa 卡最低手续费门槛）
- 98.6% 以 USDC 结算
- **笔均约 0.41 美元**
- 而且 Artemis 刷量过滤器显示：约 50% 的笔数、峰值 81% 的金额是人造活动，**过滤后 30 天真实交易量仅约 160 万美元**

算笔账：全行业 7300 万美元 × 3% = **219 万美元/年**，这是全世界 A2A 微调用能分给"网络服务费"的全部总量。再过滤掉刷量，再除以所有竞争者——**A2N 拿到的很可能是每年几万块。**

**结论：靠 agent 微调用抽成，这个项目活不下去。** 3% 的模型必须建立在**单笔 ≥ 1 元人民币的高单价任务**上，或者干脆换收费方式。

## 4. 谁会来吃这块：四面夹击

| 对手 | 优势 | 软肋 |
|---|---|---|
| **大厂智能体商店**（Coze 技能商店 2000+ 技能、开发者分成 90%；百炼；元器） | 流量、零门槛、现成支付 | 平台既当裁判又当运动员；跨生态封闭 |
| **卡组织/持牌方**（Visa TAP、Mastercard Agent Pay、银联 APOP、支付宝 ACT） | 正在抢"认证层"事实标准 | 只做信任与清算，不做任务验收 |
| **链上派**（x402 + ERC-8004） | 无国界、无账户、微支付成本 0.001 美元 | 人民币合规路径不通，公约框架下无法做核心环节 |
| **协议基金会**（Linux Foundation / AAIF） | 定义标准 | 不做商业，不做运营 |

**你的缝隙只有一条：跨平台的、异构的、需要人工验收的高单价调用 + 人民币合规 + 真正中立的第三方。** 三个条件缺一不可，但三条同时满足时，上面四位一个都做不了。

## 5. 对 A2N 的四条修正建议

### 修正一：SDK 直接长在 A2A v1.0 上，删掉自研能力发现

`node.register()` 改为发布一张**签名 Agent Card**（`/.well-known/agent.json`），调度器按 card 里的 skills 做匹配。代价：要跟 A2A 的 task 生命周期对齐。收益：立刻获得跨框架、跨云、跨企业的互操作能力，且未来 Coze / 百炼 / Bedrock 上的 agent 理论上都能被你的网络调度。

### 修正二：新增 KYA 模块 —— 这是公约送给你的商业模式

公约要求：智能体身份识别、验证、**风险分级**、全链路传递、可追溯存证。
A2N 已有的东西：信誉分体系、凭证链、验收记录、黑名单。

**它们几乎是同一套东西的两块牌子。** 把"信誉分 + 凭证链"包装成 KYA 合规基础设施，卖给需要接入支付链路的 agent 平台与持牌方——这是一个**不碰钱、不抽成、按月收订阅费**的生意，而且客户是有合规预算的 B 端，不是刷量的 C 端。

**这比 3% 抽成好得多：收入与调用量脱钩，与合规刚需挂钩。**

### 修正三：收费模型改成三层，别押注单一抽成

| 场景 | 收费方式 | 理由 |
|---|---|---|
| 高单价任务（≥1 元） | 3% 网络服务费 | 原设计成立 |
| 微调用（<1 元） | **按凭证条数的阶梯订阅**（节点/使用方月费） | 3% 不够清算成本，改收"刻章费" |
| KYA / 存证服务 | B 端订阅 | 刚需、合规预算、不碰资金 |

注意第二条的比喻：**刻章费**。这个名字比"网络服务费"好太多——它精确地描述了你在做什么（只刻章，不碰钱），而且固定费用不受客单价塌陷影响。

### 修正四：加一条铁律 —— 不只不碰钱，也不碰生意

原三铁律保证了廉洁，但没保证**中立**。如果 A2N 哪天自营 agent 或自营节点去接任务，就同时成了裁判和运动员，Coze 式的信任危机立刻复发。

**铁律四：运营方永不自营 agent、永不自营节点、永不与客户争利。** 这一条要写进对外白皮书，因为它恰恰是你能赢大厂商店的唯一理由。

## 6. 最大的风险：时序

协议成熟 ≠ 市场成熟。Juniper 预测 2030 年全球代理商务约 1.5 万亿美元，但**2026 年交易额仅约 80 亿美元**，且以零售为主——那不是"agent 调用 agent"，那是"agent 帮人下单"。

跨组织、跨平台、需要验收的付费调用，乐观估计 **2027-2028 才起量**。A2N 能不能撑到那天？

**建议：先用"算力调度"这个已经有真实付费需求的品类活着，把"agent 互调"当作 2027 年的期权，而不是 2026 年的主营。** 4090 空着也是空着，先让它接推理任务的单，账本、验收、凭证链这套东西在算力场景里跑通，等 agent 互调的潮水来了，你手里已经有一套跑了两年的结算基础设施——那时候你的壁垒不是技术，是"已经被审计了 24 个月没出过一分钱差错"这个事实。

## 7. 评分卡

| 维度 | 评分 | 说明 |
|---|---|---|
| 市场真实性 | 7 / 10 | 真实存在，但被刷量严重夸大，需按过滤口径看 |
| 时机 | 6 / 10 | 协议已就绪，付费规模未起，2027-2028 才是窗口 |
| A2N 卡位准确性 | 8 / 10 | 验收/记账/信誉这层确实真空，且公约强化了需求 |
| 原方案适配度 | 6 / 10 | 架构对，收入模型错，修正后可达 8 |
| 竞争风险 | 8 / 10（高危） | 大厂商店与持牌方双向夹击，中立是唯一护城河 |

**综合：值得做，但要换打法。** 别把自己当成"agent 版淘宝"（那是 Coze 的位置，你打不过），把自己当成**"agent 经济里的登记结算公司 + 公证处"**——不碰货、不碰钱、只盖章，靠合规刚需和公信力收钱。

---

## 8. 一句话

A2A 解决了"能不能打通"，AP2 解决了"钱怎么付出去"，x402 解决了"几分钱怎么结"——**没有人解决"活干得算不算数"。**

那正是 A2N 唯一该待的地方。但请记住：这个位置的价值不在抽成比例，在于当行业需要一个"谁都不信任的中立方"时，你的账本已经被审计了两年，而且一分钱差错都没出过。
