## 真实性边界

三天数据门槛、不同真实使用者的体验、正式发布者身份及外部平台证书不能通过修改日期或自称发行完成。实现可运行的采集、验证和签名工具，记录实际完成程度。

当前实际校准记录仍为 42 笔、三个供应身份、一个真实日期，全部为助手受托使用。活动模型为 DEFAULT；本轮受控验收不进入生产校准。信誉策略仍保持各节点原有 SHADOW，主人可以选择本地执行，软件更新不代替主人开启限制。

macOS 原生完整安装包、系统公证/发行证书、公开分发、GPU 硬件、真实独立用户与长期经济/治理效果仍需要对应环境和实际使用。创作者实际分账、更多支付协议及自动偏好学习属于后期扩展，本轮没有宣布完成。

测试钱包用于本地测试链，测试账户与网络在界面明确标识，不用于真实资金。评价、支付、网络和交易之间沿用独立端口与节点装配。
