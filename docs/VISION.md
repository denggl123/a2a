## 〇、一句话

**让全世界闲置的电脑和调好的工作流，变成人人可用的成品能力 —— 谁都不需要相信谁，也不需要被谁批准。**

三句副题，分别对应三类人：

| 对谁 | 一句话 |
|---|---|
| 手上有好 agent / 好机器的人 | 你调通的东西别人可以直接用；你的电脑自己接单、自己交付、自己记账。 |
| 电脑跟不上、agent 做得不够好的人 | 你不需要折腾 —— 说你想要什么，就有成熟的人替你做完。 |
| 只剩两台电脑、什么平台都不在的两个人 | 你们照样能互相干活、互相记账、互相验证。 |

**它不是 AI API 市场。** API 卖的是一次推理，交付完就结束了；
A2N 卖的是一次 **验收过、可归责的交付**。这一句差别贯穿全部设计（§2）。

## 二、我们到底在卖什么：成品，不是算力，也不是 API

这是整份愿景里最容易被误解、也最值钱的一条。

**你举的例子说得很清楚**：某个人能跑 h3 做视频，**把工作流全部调通了**，再包装成 agent。
于是电脑配置低的人可以直接用别人的 agent，**不需要自己折腾**。

他卖出去的**不是显卡时间**，是 **"一条被调通的、我能直接用的能力"**。
显卡时间只是这条能力里的原料 —— 而原料是全市场最便宜、最容易替代的东西。

| | 卖什么 | 用户买到的 | 结果 |
|---|---|---|---|
| **AI API** | 一次推理（token） | 一次输出 | 输出好不好、能不能用，平台不管 |
| **算力市场** | 机时 / GPU 秒 | 一段时间 | 用户还得自己搭环境、调工作流 —— **"折腾"没被消除** |
| **agent 框架 / 应用商店** | 一个可安装的东西 | 一个待配置的程序 | 配置与调参的责任仍在使用者身上 |
| **A2N** | **一次验收过的交付** | **一个结果 + 一份可验证的凭据** | 干得不好可以不认、不付钱，账还留得下 |

这一条推导出三件已在设计里的硬约束：

1. **计费单元是"验收过的任务"，不是 API 调用**（`docs/design/A2N-商业价值评估-v1.md` §1.2）。
   验收不过不收钱，全额退回 —— 这是 A2N 唯一真正的定价权。
2. **对外不暴露算力细节**（能力黑盒化：无 GPU / vram，只留 `deployment.region`；
   `gpu_seconds` 只作内部计费口径）。因为你卖的不是原料，说原料只会把用户拉回比价。
3. **卖算力必输，卖成品不可替代**：算力谁都能卖、且卖不过云厂商的 spot 市场；
   但"一次可信的交付"没人能免费给。

## 三、"够用就行"：发现是**可行域投影**，不是全量索引

> 初衷第 6 条：*每个人因为网络、网络延时、账户差异，发现的 agent 都是和别人有一定差异
> （并不是发现世界全量 agent，综合够用就行）。*

这不是妥协，**是设计目标**。每个人屏幕上那份列表，是同一个世界在他自己的约束下的投影：

| 造成差异的约束 | 机制 |
|---|---|
| 他在哪、网络多快 | 延时三口径（平台探测 `rtt_ms` / 服务端自报 `ttft` / 自报 `sla`），窗 20 |
| 他的账户能用什么付 | `a2n_account.compatible_with` —— 支付能力交集的**唯一**实现 |
| 对方是不是真的 | 卡片自证三态 `signed` / `unattested` / `invalid` + `tampered` |
| 对方稳不稳 | 试用进度、验收通过率、公开案例 |
| 对方此刻能不能接活 | 可达性判定（NAT / 直连 / 隧道 / 轮询）+ 派单前校验 |

三条由此而来的纪律：

- **没有全局目录**（自持模式三不变式之一）。注册只是允许被发现；发现是按需的。
- **不做"最大市场"**。全量索引听起来才是愿景，实际上它会让远端、低配、新上架的节点
  永远排在后面 —— 那正好违背初衷第 2、3 条。
- **"综合够用"是可验收的目标**：任何一次搜索，只要这个人所在的位置、账户、
  网络条件下能凑齐他要的东西，这个市场就是成立的。**不要求它对全世界成立。**

## 四、供给从哪来：把工作流包装成成品

### 4.1 两类供给方

| | 他有什么 | 他做什么 | 他拿什么 |
|---|---|---|---|
| **手艺人** | 一条调通的工作流 / 一个好 agent | 摆摊：说清"卖什么、多少钱"，其余全有默认值 | **全额归自己**（网络不抽成；`DEFAULT_SPLIT = {"node": 1.0}`） |
| **有机器的人** | 一张好显卡 / 一台常开的电脑 | 装一个 agent 上去（**不需要有手艺**） | 全额归自己 |

**这两类人正好是初衷第 2 条的两半**：好的 agent（手艺人）、闲置的资源（有机器的人）。
平台要做的不是替他们造能力，而是**让能力可以直接交付、可以被验收、可以被收钱**。

### 4.2 加入的门槛：零成本加入，摆摊是可选的深度

- 从"下载"到"我的电脑在为我工作"之间，**不允许存在第二个必须做出的决定**（PRODUCT §③）。
- **摆摊本质是一次创作**（卖什么、多少钱），不可能零成本 —— 所以它必须是
  **可选的深度，而不是进门门槛**。把"完善你的资料 / 配好流程"放到第一屏，就是把挂机者吓跑。

### 4.3 样本 agent（一键部署 + 创作者分成）：晚点做，理由不是价值低

它缺一个现在还没有的东西：**代码安全模型**。

- 一键部署 = 一键执行陌生人的代码；
- 卡片自证解决的是"**这是谁的**"（身份），**解决不了"它会不会翻我的文件"**（安全）；
- 要做得先有：沙箱、权限声明、签名分发。

**在此之前可以先做的**：让它以"清单 + 说明"的形式存在（照着自己装），
而不是"一键执行"。这样既保留了这条路径的种子，又不引入未建模的风险。

## 五、冷启动：两台引擎（都不是"撬需求"）

### 5.1 引擎一：免费额度 = 用"测试流量"换"可被信任"

> 初衷：*部分羊毛党可以免费薅（在全球网络甚至可以无限薅，但也是别人的测试者）。*

**"无限薅"是网络的涌现属性，不是平台发的福利。** 需求方总能找到免费的东西，是因为网络里
永远同时存在三种免费供给：

1. 每个新上架的 agent 都带着**毕业前额度**（要收钱，先服务）——
   而且**卡上没有任何退出通道**：声明 `x-a2n.trial=false` 会被上架校验**直接拒**
   （不是静默忽略：忽略会让供给方以为自己退出了，等到被计费才发现，那是欺骗）；
2. 断线重连的节点会**重新获得一小段免费额度**，用途是**采网络稳定参数** ——
   这一段里的案例**不进质量模板**（见 §5.4）；
3. 有人**自愿永久免费**（演示里的"华北·公益 OCR" 档位就是这一种）。

**"免费薅"是第三方使用者自己发现的，不是我们宣传的。** 平台从不说"永久免费"，
但也从不拦着别人这么说 —— 当"这里很多 agent 都能白试"被使用者自发传出去，
那正是冷启动该长成的样子。**被传开的是事实，不是承诺**；这两者在第一批 agent 毕业收费时，
一个是"试用结束了"，另一个是"被背叛了"。

**薅的人不是白吃。** 他交出的是：真实调用分布、完成/失败样本、评分、公开案例 ——
**这些正是供给方"毕业"所需要的证据**。所以：

> **免费的价格是"可信"，薅的价钱是"当测试者"。**

两端都不吃亏，靠的是**把"计数"与"证据"分开算**：

- 额度 **不按人计、按完成次数计** —— 谁调的都算（提供者做满 10 次活却因"没有 10 个不同的人"
  而毕不了业，体感就是被白嫖）；
- 代价是"自己调自己"也能凑数，这个代价**不靠加限制消除**，而靠把它
  **移出公开证据**（`self_source` 不进公开案例、不进评分统计）来消除；
- 但移出统计**不等于假装没发生**：界面会并排给出"**自己打的原始分均值**"与
  "**独立使用者打的原始分均值**"以及两者的**差值**（样本不足时不给差值）。
  这是**给差异，不是给结论** —— 网络不替谁判定"这是刷分"，只说"这两个数差多少、
  各有多少样本"，使用者拿它预估质量。自调用是个别人的选择；等网络里使用者足够多，
  它自然被稀释，所以不必禁止（`a2n_reputation.self_vs_independent`）。

**必须守住的口径（否则会反噬）**：

> 网络**从不说"永久免费"**。免费 = 某个 agent 的毕业后失效额度，或某个供给方的自愿公益。
> 一旦把前者说成福利，就会养出"这产品免费"的预期 ——
> 然后第一批毕业的 agent 一收费，用户感觉的是**被背叛**，而不是"试用结束了"。

### 5.2 引擎二：供给侧自转化（发起人先当第一个供给）

> 初衷：*自己可以把折腾出来有价值 agent，或者有好配置转化为提供成熟 agent 的服务器。*

三种转化，一条比一条重：

| 转化 | 前置 | 结果 |
|---|---|---|
| 有调通的工作流 → 包装成 agent 上架 | 会摆摊 | 手艺人 |
| 有好配置 → 装别人（或样本）的 agent | 会装 | 节点 |
| 两样都有 | —— | **"提供成熟 agent 的服务器"** |

**为什么这是对的第一步**：供给不需要等需求。而且发起人**自己就是最强的供给样本** ——
仓库里那四个演示档位（属地 / 价目 / 结算方式 / 延迟 / 试用状态各不同）
就是这条路径的第一个可运行版本。

### 5.3 为什么这不是"做双边"（与 `商业价值评估` §5.2 的关系）

那份评估说"不要做双边，双边同时拉两端是自杀"——**这里不矛盾，因为两台引擎不在两侧**：

- **引擎一拉的其实不是"需求"，是"测试流量"。** 它的服务对象是**供给侧的毕业要求**，
  不是 GMV。薅的人以"用户"身份出现，实际履行的是"测试者"职能。
- **引擎二拉的是供给**，由发起人自己启动。
- 所以两台引擎都在**同一侧**发力，不存在"必须同时把两端拉起来"的死亡循环。

**指标**（沿用该文档的结论，不改）：不是 GMV，而是

- **首次搜索命中率** → 决定需求侧留存；
- **验收通过率** → 决定供给侧信任。

### 5.4 免费期的有界性（否则"重启即免费"）

| 情形 | 额度 | 这些案例 | 代码 |
|---|---|---|---|
| 首装 `INITIAL` | **10 次完成** | 进质量模板（就是毕业证据） | `INITIAL_CAP = 10` |
| 重连 `RECONNECT` | 重置为 **5 次**（不是又给 10） | **不进质量模板**（采网络稳定参数用） | `RECONNECT_CAP = 5` |
| 同一身份补额频率 | 每自然日最多 1 次 | —— | `REGRANT_MIN_HOURS = 24` |
| 生命周期累计授予 | ≤ 30 次 | —— | `TOTAL_GRANT_CAP = 30` |
| 何时收费 | **毕业后**才允许 | —— | `graduate()` |

**两种额度为什么必须分开记**（`trial_offers.grant_kind` → `tasks.trial_kind`）：
首装那 10 次是用来**换毕业证据**的；重连那 5 次是用来**采网络稳定参数**的。
把后者也当质量证据，等于拿"节点刚上线、网络还没稳"时的表现去评价它交付得好不好。
被排除的样本数照样对外报出来（`stability_calls` / `stability_samples` / `case_counts`）——
**隔离不等于隐藏**。

**重连补额是弱约束**：不检测"你究竟断没断过网"，只靠每日 1 次 + 累计 ≤30 兜住滥用。
理由是"随意断网刷额度"真正的代价是**影响使用**，而过重的闸门同样影响使用 ——
宁可留这一点缝，也不假装能查清。

**只有"完成"的调用吃额度**（失败、超时、被退回都不计）——
不能让失败吃掉额度，那是拿提供者的钱替链路问题买单（`consume()` 只在验收通过路径调用）。

## 六、诚信铁律（愿景层面的"不许说的话"）

三条，比任何功能重要。

### 6.1 网络造不出成熟，只能让成熟可见

- **能兑现的**：让成熟可验证、让不成熟藏不住。
- **不能说的**：*我们提供成熟的产品*、*已审核*、*官方优选*。
- **落点**（已在代码里）：给证据不给结论 —— 多段分开、**绝不合成总分**；
  试用 10 次后带真实案例毕业；评分锚在**"该评分者给所有人的平均"**（同源不计入）；
  争议可仲裁；误差不影响"通过与否"的判定。

> 初衷第 4 条"提供成熟的产品"要按这个口径翻译成对外语言：
> **不是我们保证它成熟，而是成熟在这里藏不住、不成熟在这里待不下去。**

### 6.2 不做交易对手（"不是自己赚钱"的正确读法）

"不是说自己赚钱"是对的姿态，但要写得能执行：

- 中立层**不赚差价、不囤货、不优先卖自己的**；
- **公证与结算也不收任何费用**（2026-09-18 拍板）：网络是**纯公益**的 —— 一次调用结算
  多少，节点就拿到多少（`DEFAULT_SPLIT = {"node": 1.0}`）。托管商的角色是**兑换与清算**
  （把不同货币换成积分，让互不相通的账户能对上账），它**不是收费方**；
- 不可越的线：**一旦某个角色既能决定你被不被看见、又能从中收费，中间商就回来了**
  （PRODUCT §1.6）。所以"会合与寻址"这类公共设施**不可以是生意**。

> "要不要收手续费"这件事**已经吵完了，答案是不收** —— 而且它不是靠承诺，是靠账本：
> 谁也没从你的调用里抽走一分钱，这一点随时可以自己算出来。

### 6.3 "赚钱"必须诚实定义

| 规模 | 用户得到的东西 | 产品里怎么称呼 |
|---|---|---|
| 两台电脑（同一 Wi-Fi） | 没有钱也有用：互相干活、互相记账、互相验证 | **交换** |
| 网络小 | 账面等价物：谁欠谁多少，且能被凭证证明、可转让 | **债权** |
| 网络大 | 真实需求方带着钱进来，钱只经用户自己的通道，产品不保管 | **收入** |

**绝不能出现"你的电脑在赚钱"，而账上其实是一串平台发的积分。**

## 七、我们不做什么（愿景层面的边界）

| 绝不做 | 为什么它会诱惑我们 |
|---|---|
| **卖算力**（卖机时 / GPU 秒） | 好懂、好计量、好融资 —— 但那是和云厂商拼价格，必输；且它把"折腾"还给了用户 |
| **追求全量目录 / 最大市场** | "全球 agent 索引"听起来就是愿景，但它让远端与低配节点永远排在后面 |
| **平台托管资金** | 托管是最容易收手续费的地方 |
| **出卖排序**（推荐位、置顶） | 最自然、最赚钱、也最快把"没有中间商"变成谎话的一步 |
| **把免费说成福利** | 一开口就把"毕业"变成"背叛" |
| **把"未签收"说成"已收入"** | 数字好看，第一天就能做出漂亮的增长曲线 |
| **一键执行陌生人的代码**（在安全模型建成前） | 那是"零门槛"最性感的形态 |

## 九、阶段

### 9.1 已经立住的（v1：23 个包 / 426 项测试）

成品交付的骨架全部到位：**发现**（无全局目录）、**调用**（治理链 `POST /v1/invoke`）、
**验收**（双向计量）、**结算**（单表幂等 + 日切）、**凭证**（卡片自证 + 公证章）、
**自持**（无服务器 / 无托管 / 无积分）。

### 9.2 下一步：愿景兑现的三个缺口

1. **首发垂直** —— 窄到"前 20 个 agent 就填满'够用'两个字"，
   窄到能说清"你为什么该先来这里挂你的 agent"。
2. **一句能兑现的对外承诺** —— 按 §6.1 的口径写，不写"我们提供成熟产品"。
3. **写下来的收入伦理** —— 按 §6.2，把"不当交易对手"变成可执行判据。

### 9.3 远期

**样本 agent 的一键部署 + 创作者分成**（初衷第 5 条）。
前置条件不是市场，是**代码安全模型**：沙箱 / 权限声明 / 签名分发。

## 十、验收：这个愿景怎么算成立

五条可观察的行为，不看功能清单：

1. **两个⼈、两台电脑、没有任何平台**：能互相发现、互相调用、各自手里的凭据能对上。
   （已可演示：`python scripts/sovereign_demo.py`）
2. **一个低配电脑的用户**：不装本地模型、不调参数，拿到一条**只有在他自己机器上跑不出来**的结果，
   并且能验证对方在交付边界上签了字。
3. **一个刚上架的 agent**：10 次免费服务之后，详情页上**有真实案例与评分**，然后才收到第一笔钱。
4. **一个断网一个月的节点**：重新入网时**先免费服务 5 次**，而不是直接恢复收费。
5. **任何人都买不到更好的位置**：没有人能付费让自己的 agent 排到前面。

本文上一版在这里列了四个"与初衷有落差"的待定项。发起人已逐条定调，下面是决定本身

| # | 决定 | 为什么这样定 | 代码落点 |
|---|---|---|---|
| 1 | **卡上不允许声明退出免费期**。任何想被发现的 agent，前 10 次完成调用系统一律不计费 | 这条的目的不在补贴，在**使用方**：任何人都能先拿真实案例看看这东西是不是自己要的。留出口 = 让第一批使用者以为自己能白试，然后被收费 —— 那是背叛 | `trial.policy_for` 只看部署开关；`validate_card` 对 `x-a2n.trial=false` **直接拒**；`tests/test_quality.py::test_card_cannot_opt_out_of_the_free_period` |
| 2 | **重连补额的用途是"重新上线采网络稳定参数"**，这些案例**不进质量模板**；并且是**弱约束** | 节点刚重连时网络还没稳，拿那时的表现评价"交付得好不好"是错的。但也不该为了防刷而加一道重闸 —— "随意断网"真正的代价是影响使用，过重的闸门同样影响使用 | `grant_kind=RECONNECT` → `tasks.trial_kind` → `ratings.stability`；`quality_facts` / `counts` / `summary` / `case_list` 四处过滤，**同时**逐处报出被排除的条数 |
| 3 | **"免费薅"是第三方使用者自己发现并自发宣传的**，不是平台宣传的；网络从不承诺永久免费 | 被传开的必须是**事实**（"这里很多 agent 都能白试"），不是**承诺**。两者的差别只在第一批 agent 毕业收费那天显形：一个是"试用结束了"，另一个是"被背叛了" | 口径写死在 §5.1；对外文案不得出现"永久免费"（§7） |
