# 可安装工作流、成果与本机维护

## 模块边界

业务仍共用既有供给、投影、调用、样品、评价、争议和支付账本。发现协调层负责找到节点和供给；自然语言条件解析、关键词匹配、任务类别、选择效果均在本机展示与评估层。整理条件不执行发现或 Agent。

评估层只调用装配的 `ReviewerPort`。节点提供代码用例、语义接口、实际成果规格适配；不让质量算法直接调用支付或公共发现。人工体验与助手验收分开，缺少专业评审器时保持 UNKNOWN。

复杂预览与评审在独立后台工作线程执行。私有文件授权、技术交付与付款事实先保存，容器解析不占用交易账本事务。评审修订和取消仍使用版本检查；预览失败不抹掉交付。

原成果可以按原规则显式重新检查，保留原体验和修改链，不再次调用或收费。预览解析失败后，软件或授权解析依赖发生变化时仅重试一次；不会反复空转。视频缩略图失败不丢弃已解析的真实规格。

## 可安装工作流

账户页支持本节点签署、导入、预览、授权、安装和回滚 `a2n-container-workflow/1` 清单。清单固定发布者、包名、版本、不可变镜像摘要、执行命令、资源和权限。同一发布者和包名对应固定供给 ID；所有历史版本不可替换。安装后在供给页明确上架，原样品与信誉继续保留。

默认资源限制：无网络、只读根文件系统、无主机文件挂载、无额外能力、非特权用户、32 个进程、一个 CPU、独立临时空间；清单限制内存和时间。GPU 必须声明并授权，本轮没有 GPU 硬件验收。Python、媒体工具或模型应预装在固定摘要的镜像中。

容器标准输出（包括进度）合计最多 1 MiB；默认 JSON 输入最多 1 MiB，声明扩大后硬上限 16 MiB。大文件应使用既有私有资产接口交付，不能把文件容量上限理解成允许同等大小的内联容器 JSON。

依赖下载需要另行授权，并成为持久安装任务。失败和重启中断可以明确重试；不自动执行更换后的程序。离线镜像 ID 需要先在节点电脑安装，远程下载要求 `仓库@sha256:摘要`。

Windows 使用已安装的 Docker 引擎。Docker 节点的容器执行可用 `docker/workflows.yaml` 叠加启用：只有节点控制进程访问主机引擎，执行的 Agent 容器不获得引擎套接字。应把节点控制进程作为电脑主人授权的完整软件来安装。

## 独立检查与成果预览

- 代码：买方先固定函数、输入和预期结果，实际代码在受限容器中运行；预期答案留在买方节点，由节点比较返回值。
- 语义：电脑主人配置并授权内容评审地址，明确发送所选结果与要求；接口为 `a2n-quality-evaluator/1`，返回 0–1 的 score。有超时、大小限制和禁止重定向。来源标明为配置的评审器，不冒充人工评价。
- 成果：读取实际私有文件，解析图像尺寸、WAV 时长/采样率、文本/文档内容、PDF 页数和视频规格。PDF、视频需要授权的解析镜像。
- 私有查看：签名获取后支持图片、音频、视频、PDF 与文本预览，仍校验交易关系、授权、范围和完整哈希。HTML 等可执行格式不能内联打开。
- 公开样品：前十次免费技术交付一定公开。原始附件留在私有交付中；公共页使用经节点重编码的小 PNG、音频波形、视频预览及脱敏文本摘要。自动处理不能识别所有画面中的私人信息；调用前的强制公开提示继续生效。

文件容量可由主人设置：单文件最高 1 GiB、资产总量最高 64 GiB、最多 4096 个文件。保留默认 16 MiB / 128 MiB；接近容量或磁盘不足时显示提醒。媒体检查单次最多读取 8 MiB，超过时规格检查保持未知，不影响完整私有文件交付。

## 维护与历史

定期备份由节点自身运行，不依赖开发工具。默认关闭；主人设置恢复口令、间隔和保留份数，口令只存入既有加密存储。仅轮换本模块创建的备份，手动备份、财务、评价与交易历史保留。

已完成任务评审和非活动校准模型可移到加密归档。等待任务和活动模型受保护；按原 ID 仍能读取，列表支持 `archived=true`、`limit` 和 `offset`。归档不改变评审数据、反馈或付款状态。

发行工具使用独立、持久、受系统保护的项目发布者密钥，生成可由现有升级协议验证的清单。它与普通用户节点身份分开。Windows 构建包含运行时和五个包；`install.sh` 提供 Linux/macOS 源码安装入口，依赖系统 Python 3。macOS 原生完整安装包、系统公证证书与公开分发渠道仍需相应环境。

发行序号超过浏览器安全整数范围时使用规范十进制字符串，保持导入、签名和防回退比较一致；兼容历史整数清单。
